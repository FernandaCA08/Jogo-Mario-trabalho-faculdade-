# 🍄 Jogo Mario — Trabalho da Faculdade

## 📖 Sobre o Projeto

Este projeto foi desenvolvido como trabalho acadêmico com o objetivo de aplicar conceitos fundamentais de desenvolvimento web utilizando **HTML**, **CSS** e **JavaScript**.

O jogo é inspirado no universo clássico do **Super Mario**, trazendo mecânicas simples de movimentação, obstáculos e interação em um ambiente 2D.

Além da parte visual, o projeto também teve como foco o desenvolvimento da lógica de programação, manipulação do DOM e organização de arquivos front-end.

